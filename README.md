# 声播学院 · 在线课程系统

面向声乐学习者与开播主播的在线课程原型，包含**用户端**与**管理员后台**两套相互隔离的界面。原生 HTML/CSS/JS 编写，无需构建，浏览器直接打开 `index.html` 即可运行；电脑端与手机端自适应。

## 运行方式

- 直接双击 `index.html`，或用浏览器打开该文件。
- 无需安装任何依赖；仅 B 站视频播放需要联网。
- 推荐 Chrome / Edge 最新版；手机浏览器同样可用。

## 功能清单

### 用户端

- 注册、登录、退出，路由守卫
- 声乐课与开播运营两个独立模块，各 6 门内置课，章节课时结构
- B 站视频内嵌播放：不跳转、有声音，支持横屏/竖屏切换与全屏
- 每日打卡、连续天数、学习时长自动累计、学习进度百分比
- 学习提醒开关与时间设置（本地设置，系统推送开发中）
- 每节课后 10 道选择题；章节完成后章节考试 + 实操任务
- 直播数据复盘：单场与近一周两种模式，六维加权评分、每日趋势、AI 结构化分析
- 我的页面：学习概览、收藏、学习记录、昵称修改、会员中心（开发中占位）

### 管理员后台

- 仪表盘：课程、上架、用户、打卡统计
- 课程管理：新建、编辑（章节/课时/BV 号）、上架、下架、删除自定义课
- 用户管理：自定义修改密码、一键重置为 `123456`
- 管理员账号：列表与新增管理员
- 评分标准：六维权重与满分配置，一键生成并复制评分标准文档
- 会员管理：开发中占位

## 已知限制（原型期）

1. 数据保存在浏览器 localStorage，清缓存或换浏览器会丢失，多设备不同步。
2. 密码为本地明文演示，上线需改为后端哈希 + Token 鉴权。
3. B 站视频是否允许嵌入取决于上传者设置；失效后可在后台逐课时替换 BV 号。
4. 学习时长为页面计时（iframe 跨域无法读取真实播放状态）。
5. AI 复盘当前为规则引擎分析，豆包大模型接口已预留，上线后由后端代理调用（密钥不落前端）。
6. 会员、支付、系统推送、真实作品上传均为开发中占位。
